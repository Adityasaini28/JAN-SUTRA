# JAN SUTRA — Analytical Methodology

## 1. Problem definition

Citizen feedback is high-volume but fragmented across issues, locations and time. The objective is to reduce the distance between raw feedback and an actionable governance hypothesis.

## 2. Trend analysis

For each issue, monthly negative-sentiment share is compared with its historical mean and standard deviation.

A large positive deviation plus a meaningful month-on-month increase is flagged as **Escalating**.

This is a screening signal, not proof of a structural deterioration.

## 3. Hypothesis triangulation

The engine combines:
1. complaint concentration by service sub-driver;
2. district-level association between dissatisfaction and a relevant service-capacity indicator;
3. explicit data gaps requiring operational verification.

Correlation is deliberately reported as association.

## 4. Priority score

The Governance Priority Score combines:
- prevalence: 25%
- negative sentiment: 25%
- trend severity: 20%
- population exposure: 15%
- evidence availability: 15%

Each component is displayed separately so the final score is auditable.

## 5. Action governance

The system does not claim that citizen feedback proves an intervention will work.

Each action therefore has:
- a proposed lever;
- an accountable owner;
- validation data;
- a measurable success metric.

## 6. Fieldwork bridge

The next analytical step is field verification:
- sample affected locations;
- validate the reported service condition;
- reconcile citizen reports with administrative records;
- document contradictory evidence;
- update the hypothesis before recommending implementation.

## 7. Data boundary

The current dataset is synthetic and intentionally reproducible. It should not be presented as actual voter sentiment, actual district performance, or an empirical estimate of public opinion.
